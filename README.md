# MabiUtils 배포

최신 버전은 **1.2.15**입니다.

새로 설치하면 `프리셋 1`의 다섯 기본 던전마다 파티원 `1번`부터 `4번`까지 명단이 바로 준비됩니다. 기존에 저장한 파티원 이름과 디버프 배정은 바뀌지 않습니다.

디버프 목록이 펼쳐져 있을 때는 `◀`를 눌러 아이콘과 토글만 보이게 접고, 접힌 상태에서는 `▶`를 눌러 원래 목록과 창 폭으로 돌아갈 수 있습니다. 스크롤·토글·드래그 배정은 접힌 상태에서도 그대로 사용할 수 있습니다.

메인 화면과 설정·계산기·도움말·로그 같은 보조 창의 맨 위 빈 제목 영역을 더블클릭하면 작업 표시줄로 최소화하지 않고 제목줄만 남겨 접을 수 있습니다. 같은 곳을 다시 더블클릭하면 접기 전 크기로 돌아오며 버튼·글자 링크·입력칸 위에서는 접히지 않습니다.

메인 화면과 보조 창은 Esc로 닫을 수 있습니다. 처음 실행할 때 Windows 자동 실행과 닫을 때 트레이 최소화는 모두 꺼져 있으며, 메인 Esc는 X와 같은 종료 선택 흐름을 사용합니다.

## 설치 방법

1. `MabiUtils_V1.2.15.zip`을 받습니다.
2. ZIP을 원하는 폴더에 전부 압축 해제합니다.
3. 압축을 푼 폴더의 `MabiUtils.exe`를 실행합니다.

`MabiUtils.exe`만 따로 옮기면 아이콘이나 음성 파일을 불러오지 못할 수 있으므로 반드시 ZIP 전체를 압축 해제해 사용하세요.

## 파일 안내

- `MabiUtils_V1.2.15.zip`: 다른 PC에 전달할 수 있는 최신 전체 배포 묶음
- `MabiUtils.exe`와 `assets`: 압축 해제 없이 현재 버전을 바로 확인할 때 사용하는 파일
- `version.json`: 프로그램의 새 버전 확인에 사용하는 버전·다운로드 주소·검증 해시

배포 저장소에는 혼동을 막기 위해 최신 버전 ZIP만 유지합니다.

ZIP의 SHA-256 값은 `version.json`의 `sha256`에서 확인할 수 있습니다.
