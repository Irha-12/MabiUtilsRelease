# MabiUtils 배포

최신 버전은 **1.2.4**입니다.

메인 화면 위쪽의 `최신 버전 업데이트`와 `패치 노트`가 같은 색상의 글자 링크로 표시됩니다. 이제 실제 글자 위에서만 손 모양과 클릭이 동작하며 양옆 빈 공간은 눌리지 않습니다.

## 설치 방법

1. `MabiUtils_V1.2.4.zip`을 받습니다.
2. ZIP을 원하는 폴더에 전부 압축 해제합니다.
3. 압축을 푼 폴더의 `MabiUtils.exe`를 실행합니다.

`MabiUtils.exe`만 따로 옮기면 아이콘이나 음성 파일을 불러오지 못할 수 있으므로 반드시 ZIP 전체를 압축 해제해 사용하세요.

## 파일 안내

- `MabiUtils_V1.2.4.zip`: 다른 PC에 전달할 수 있는 최신 전체 배포 묶음
- `MabiUtils.exe`와 `assets`: 압축 해제 없이 현재 버전을 바로 확인할 때 사용하는 파일
- `version.json`: 프로그램의 새 버전 확인에 사용하는 버전·다운로드 주소·검증 해시

배포 저장소에는 혼동을 막기 위해 최신 버전 ZIP만 유지합니다.

ZIP의 SHA-256 값은 `version.json`의 `sha256`에서 확인할 수 있습니다.
