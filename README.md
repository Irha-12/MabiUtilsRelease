# MabiUtils (네이티브 C++판)

MabiUtils는 Windows 네이티브 C++20으로 만든 버프 알리미와 전투 도구 모음입니다. 공개 메뉴의 화면 캡처·PP-OCRv5 한국어/Windows OCR·아이콘 매칭·음성 재생 기능은 외부 서버 없이 로컬에서 동작합니다. 경매장 수수료와 브리 레흐 상점만 공식 NEXON Open API 시세를 사용합니다.

## 실행

1. [MabiUtilsRelease](https://github.com/Irha-12/MabiUtilsRelease)에서 최신 버전 ZIP을 받아 압축을 푼 뒤 폴더 전체를 사용합니다. `MabiUtils.exe`만 따로 복사하면 아이콘·음성 리소스를 불러올 수 없습니다.
2. `release\MabiUtils.exe`를 실행합니다. 같은 폴더의 `assets`는 이동하거나 삭제하지 않습니다.
3. 상단의 `영역 지정 선택`에서 버프, 디버프, 투아림, 사념파 영역을 한 번씩 지정합니다. 지정 위치와 스캔 스위치는 다음 실행에도 저장됩니다.
4. `▶ 실시간 스캔`을 누릅니다.
5. 4관 헤일로 타이머는 상단 `도구 > 헤일로 알리미`에서 엽니다. 먼저 `▶ 알림 시작`을 누르거나 전역 단축키 `Ctrl + Alt + H`로 타이머를 시작한 뒤 `오차 보정`에서 실제 헤일로가 계산보다 `늦게` 나오는지 `빨리` 나오는지 선택하고 분·초 차이를 입력합니다. 방향은 알림 버튼을 누른 시점이 아니라 헤일로 발생 시각 기준입니다. 예를 들어 기본 첫 헤일로가 1분 3초 뒤라면 `늦게 00분 10초`는 1분 13초 뒤로 미루고, `빨리 00분 10초`는 53초 뒤로 앞당깁니다. 입력이나 방향을 바꾸는 즉시 시작 시각·다음 헤일로·전체 남은 시간·14칸 일정·오버레이가 함께 갱신됩니다. 같은 단축키를 다시 누르면 알림이 중지됩니다. 헤일로 창의 `X` 왼쪽 톱니바퀴에서 단축키를 변경하고 오버레이의 글자와 배경 투명도를 각각 0~100%로 조절할 수 있습니다. 헤일로 알리미는 시작·경계·종료 때 시스템 소리를 내지 않고 화면과 오버레이만 갱신합니다.
6. 파티 디버프 담당표는 `도구 > 던전 디버프 분배`에서 엽니다. 새 설치의 `프리셋 1`에는 `글렌 베르나`, `크롬바스`, `크롬바스 심연`, `브리 레흐 믿음의 균열`, `브리 레흐`가 요청한 관문·체력 구간 기믹과 함께 들어갑니다. 글렌 베르나·크롬바스는 관문과 기믹이 없고, 믿음의 균열은 관문 탭 없이 `80% 박애의 결속 / 65% 분열의 충돌 / 50% 깃털 쇄도 / 35% 편애의 행적 / 15% 영검의 심판`을 표시합니다. 크롬바스 심연은 1~3번 방 중 3번 방에 85%~15% 기믹 6개가 들어갑니다. 브리 레흐 1관은 `85% 광물(타수) / 70% 고대 자이언트 / 55% 피자 패턴 / 50% 2페이즈 / 35% 광물(타수) / 25% 고대 자이언트 / 15% 피자 패턴`, 2관은 기믹 없음, 3관은 기존 5개 기믹입니다. 구조는 `던전 → 관문 → 기믹 → 파티원`이고 관문은 1~6개, 기믹은 관문마다 0~7개, 파티원은 1~8명입니다. 빈 구조는 `관문 없음`·`기믹 없음`으로 표시되며 `+`로 추가할 수 있습니다. 기믹 연필 버튼은 `체력 | 기믹 내용` 두 입력칸을 열어 `80%` 같은 발동 체력과 이름을 따로 저장합니다. 프리셋과 던전 목록 아래의 `+ / ✎ / ⧉ / −`는 추가·이름 변경·전체 복사·삭제이며, 복사 아이콘을 누르고 새 이름을 입력하면 파티원·그룹·관문·기믹·디버프 배정·커스텀 행동 지시까지 깊은 복사됩니다. 관문이나 기믹이 없어도 내부 기본 배정에 파티원별 디버프·그룹·여러 줄 행동 지시를 토글 또는 드래그로 즉시 지정하고 저장·복사할 수 있으며, 나중에 첫 관문이나 기믹을 추가하면 그 내용이 첫 항목에 그대로 이어집니다. 중앙 파티원은 세로 행과 전체 디버프 칩으로 표시되고 칩 `×` 단건 해제, 파티원별 복사, 그룹별 복사·해제, 파티원 드래그 그룹 합치기를 지원합니다. 파티원 연필 창에서는 이름·그룹·현재 할당 전체와 함께 이동·조 편성·잔여 역할 같은 여러 줄 행동 지시를 현재 기믹 또는 기본 배정에 저장합니다. 가운데 오른쪽 목록은 핵심·추가·펫 순서이며 스위치나 파티원 행으로의 드래그로 배정합니다. 드래그 표시는 오른쪽 배정 문서와 겹치려 할 때 보이는 쪽으로 자동 이동하므로 이름과 아이콘이 가려지지 않습니다. 목록 머리글의 화살표를 누르면 실제 아이콘과 토글만 남기고 목록과 창 폭이 함께 줄어들며, 각 아이콘은 좌우 3픽셀 여백만 둔 카드에 놓이고 토글은 바로 아래에 세로 정렬됩니다. 화살표는 다른 작은 조작 버튼과 같은 크기·색상으로 정중앙에 표시되고 `디버프` 제목과 함께 `배정 문서` 제목 크기로 보입니다. 다시 누르면 원래 폭으로 돌아옵니다. 보조 글자는 `#A8B1FF`, 선택·담당·그룹 강조는 `#C9D1FF`를 사용하고 형광 민트·청록은 사용하지 않습니다. 오른쪽 끝의 편집 가능한 배정 문서는 `현재 기믹 | 모든 기믹 | 복사`를 제공하며, 모든 기믹은 현재 관문만 대상으로 `[던전명 관문명]`, `[기믹]`, `이름 : 디버프 + 행동 지시` 형식을 만듭니다. 담당이 없는 파티원도 빈 줄로 유지되고 사용자가 메모장처럼 고친 화면 내용을 그대로 복사합니다. 문서 글자는 `던전 리스트` 제목과 비슷한 크기로 표시되고 선택 범위나 저장된 배정이 바뀌면 자동 재생성됩니다. 배정 문서와 행동 지시 입력란은 Windows 기본 흰색 막대 대신 디버프 목록과 같은 연보라 커스텀 스크롤을 사용하며, 휠·트랙 클릭·손잡이 드래그로 7번째 기믹의 마지막 줄까지 이동합니다. 파티 배정표나 디버프 목록 위로 마우스를 반복해서 움직이거나 디버프 목록을 접고 펼쳐도 부모 화면이 배정 문서를 덮지 않으므로 내용이 계속 유지되고 순간적으로 비었다 나타나는 깜박임이 없습니다. 던전 안의 이름·복사·파티원 편집 팝업은 제목·입력값·단축키 안내를 한 단계 큰 SemiBold/Bold ClearType 글자로 표시합니다. 구버전 저장 파일은 기존 이름·배정·그룹·관문 표시를 보존하고 행동 지시는 빈 값으로 이관합니다.
7. 계산기는 `도구 > 계산기`에서 오른쪽 서브메뉴를 연 뒤 선택합니다. `경매장 수수료`는 판매가 `0`으로 시작하며 일반 5%/프리미엄 플러스 4% 수수료, 기타 비용, 1~8인과 10·20·30·50·100% 쿠폰을 비교합니다. 각 카드에는 `순수익 = 판매가 - 적용 수수료 - 현재 쿠폰가 - 기타 비용`과 그 순수익을 파티 인원으로 나눈 `1인 정산`을 함께 표시하고 가장 유리한 옵션을 강조합니다. 카드 오른쪽의 `복사`를 누르면 해당 옵션의 `1인 정산` 숫자만 쉼표·단위 없이 복사되어 게임 입력칸에 바로 붙여넣을 수 있습니다. 창을 열면 내부 시세 연결로 5개 쿠폰의 현재 경매장 최저가를 백그라운드에서 불러오고, 10분마다 자동 갱신하거나 `시세 갱신` 버튼으로 즉시 다시 조회합니다. 각 쿠폰 카드의 `실시간 최저가` 표기와 마지막 조회 시각으로 반영 여부를 확인할 수 있습니다. 시세 오류·매물 없음일 때는 기존 값이 유지되며 카드 가격을 직접 수정해 순수익과 1인 정산을 즉시 다시 계산할 수도 있습니다. `브리 레흐 구슬 분배`는 1~3관 출현 횟수 또는 전체 출현 합계, 구슬 단가, 1~8인을 받아 `출현 합계 × 2 × 단가`를 원 단위 올림과 1숲 단위 올림으로 나누고 결과를 복사하며 네트워크 없이 동작합니다. `브리 레흐 상점`은 거래 불가인 기본 구슬 교환품 29개의 아이템 명·필요 구슬·경매장 최저가·7일 평균가와 1단계 제작 재료·최종 판매 재료의 현재 시세·구슬당 가치·구슬당 순이익을 표로 보여 줍니다. 창은 기본 1480×800으로 넓게 열리고 아이템 명 열도 이전보다 넓게 표시되며, 화면 작업 영역이 더 작으면 닫기 버튼과 오른쪽 상세가 가려지지 않도록 창 크기와 위치가 자동으로 맞춰집니다. 표 머리글의 세로 경계에 마우스를 올려 좌우 화살표가 나오면 드래그해 인접한 두 열의 폭을 조절할 수 있으며, 조절한 열 폭은 놓는 즉시 저장되어 앱을 다시 실행해도 유지됩니다. 구슬 매입가는 처음 열 때 `350,000 G`로 입력되어 있으며 필요하면 즉시 바꿀 수 있습니다. 시세 갱신은 백그라운드에서 진행되므로 갱신 중에도 ?·최소화·닫기 등 창 조작 버튼은 바로 사용할 수 있고 누를 수 있는 곳에는 손 모양 포인터가 표시됩니다. 기본 효율 순위는 검증된 거래 가능 중간 재료 16종만 비교하며 소울 장비 29종과 사용자 추가 제작식은 목록 편집과 기존 자료 호환을 위해 보존합니다. 행을 고르면 처음 만드는 재료와 최종 판매 재료의 현재가, 구슬당 가치, 구슬당 순이익, 보유 구슬 기준 총 순가치·총 순이익과 1단계 투입·산출 수량, 전체 상점 재료의 구슬 비용, 판매액·수수료·일반 재료비·제작비를 오른쪽에서 확인할 수 있습니다. 순이익은 입력한 구슬 매입가를 원가로 빼서 계산하며 이익은 초록색, 손해는 빨간색으로 표시됩니다. 선택 재료 이름 오른쪽의 `제작식`을 누르면 최종 판매 재료를 루트로 하는 제작 트리가 열리고, 단계별 산출과 구슬 상점 재료·경매장 구매 재료를 분리해 필요 수량·현재 단가·재료별 소계·필요 구슬을 보여 줍니다. 마지막 `경매장 재료 합계`는 계산 요약의 재료비와 같으며 긴 트리는 마우스 휠로 끝까지 확인합니다. 계산 요약의 긴 금액은 골드 단위를 한 번만 붙여 앞자리까지 보이게 표시합니다. 같은 재료가 최종 제작과 하위 제작에 함께 필요하면 두 투입을 모두 표시하고 총수량을 계산식과 맞춥니다. `?` 도움말은 선택 재료의 1~N단계 제작 경로를 15단계 수익 계산 앞에 표시하고 긴 내용은 끝까지 스크롤됩니다. 목록 편집의 교환품과 45개 제작식은 각각 스크롤할 수 있고 시세 연결 정보는 UI에 노출하지 않습니다. `실시간 최저가`와 `7일 평균가` 중 계산 기준을 고를 수 있으며, 7일 평균은 공식 최근 거래 내역을 앱이 로컬에 누적한 거래량 가중 평균이라 첫 실행 직후에는 `수집 중`이 정상입니다.
8. 메인 창 오른쪽 위의 톱니바퀴에서 설정 창을 열면 하단 `설정 관리`에 `↓ 백업`과 `↑ 복원`이 있습니다. 백업은 일반 설정, 던전·프리셋·디버프 배정, 브리레흐 사용자 목록과 시세 기록을 하나의 `.mabiutils-backup` 파일로 저장합니다. API 키와 음악 던전 로그는 포함하지 않습니다. 복원은 파일 전체를 먼저 검증한 뒤 확인을 거쳐 현재 설정을 교체하고 즉시 화면과 Windows 자동 실행 설정에 반영합니다.
9. 메인 창 오른쪽 위의 `?`를 누르면 전체 도움말이 열립니다. 왼쪽의 `빠른 시작 / 영역 지정 / 실시간 스캔 / 인식 목록 / 오버레이 / 프리셋 / 도구 / 설정 / 문제 해결` 목차에서 원하는 메뉴를 고르고 오른쪽 안내를 스크롤합니다. 긴 설명도 고정된 글자 열과 일정한 행 간격으로 나뉘어 불릿과 첫 줄이 가지런히 표시됩니다. 특히 `영역 지정`에는 게임 화면 준비, `영역 지정 선택`에서 영역 고르기, 아이콘 전체와 남은 시간을 포함해 드래그하기, 체크 표시·스캔 스위치 확인, 실시간 스캔 시작과 인식 실패 해결 순서가 자세히 적혀 있습니다. 상단 `−`로 도움말만 최소화하고 `×` 또는 Esc로 닫을 수 있습니다.
10. 메인 창 오른쪽 위의 `패치 노트` 글자 링크를 누르면 최근에 추가되거나 달라진 사용자 기능을 날짜별로 확인할 수 있습니다. 카드 높이는 내용 수에 맞춰 늘어나며 픽셀 단위 휠 스크롤과 스크롤바로 긴 내용도 끝까지 볼 수 있습니다. 앱 시작 뒤 더 높은 배포 버전이 확인되면 왼쪽에 `최신 버전 업데이트` 글자 링크가 나타납니다. 두 링크 모두 배경과 테두리 없이 기본 `#A8B1FF`, 마우스를 올리면 `#C9D1FF`로 표시되고 실제 글자 위에서만 손 모양과 클릭이 동작합니다. 업데이트 링크를 누르면 최신 전체 패키지 ZIP을 열며 같은 버전·이전 버전·오프라인 상태에서는 나타나지 않습니다.
11. MabiUtils가 이미 실행 중이면 앱과 같은 다크 테마 선택창에서 `기존 창 열기`, `기존 앱 종료 후 새로 실행`, `새 인스턴스 추가 실행`, `취소` 중 하나를 선택할 수 있습니다. 마우스 또는 `↑/↓`, `Tab`, `Enter`, `Esc`로 조작할 수 있으며 닫을 때 트레이 최소화한 기존 창도 자동으로 감지합니다.
12. 처음 실행할 때 `윈도우 시작 시 자동 실행`과 `닫을 때 시스템 트레이로 최소화`는 모두 꺼져 있습니다. 트레이 설정을 켜면 메인 창의 `X`나 Esc를 누르는 즉시 트레이로 이동하고, 꺼져 있으면 전용 다크 창에서 `종료`, `윈도우 트레이`, `취소` 중 하나를 고릅니다. 도움말·패치 노트·설정·계산기·음악 던전 로그 등 보조 창은 `−`로 각각 최소화하고 `×` 또는 Esc로 닫을 수 있습니다. 입력이나 하위 창이 열려 있으면 첫 Esc가 해당 작업을 취소하고 다음 Esc가 창을 닫습니다. 메인과 보조 창의 맨 위 빈 제목 영역을 더블클릭하면 작업 표시줄로 내리지 않고 제목줄만 남겨 접히며, 같은 곳을 다시 더블클릭하면 접기 전 위치와 크기로 복원됩니다. 버튼·글자 링크·입력칸 위의 더블클릭은 접기로 처리하지 않습니다.

설정 파일은 `%LOCALAPPDATA%\MabiUtils\config.ini`, 던전 디버프 배정은 `%LOCALAPPDATA%\MabiUtils\dungeon_debuffs.ini`, 음악 던전 로그는 `%LOCALAPPDATA%\MabiUtils\logs`에 저장됩니다. 브리 레흐 사용자 목록은 `%LOCALAPPDATA%\MabiUtils\brielech_catalog.ini`, 최대 30일 동안 보존하고 최근 7일을 화면 계산에 사용하는 시세 원본은 `%LOCALAPPDATA%\MabiUtils\brielech_market.dat`입니다. 설정 백업은 앞의 네 설정·데이터 파일만 고정 목록으로 담고 `secrets.dat`와 `logs`는 제외합니다. 공식 배포 EXE는 빌드 때마다 새 키와 IV로 암호화·인증한 NEXON API 연결 정보를 리소스로 포함하며 UI·로그·Git·평문 설정에는 값을 표시하지 않습니다. 내장 정보가 없는 개발 빌드는 현재 Windows 사용자만 복호화할 수 있는 DPAPI `secrets.dat`, 그다음 구버전 선언을 호환 경로로 사용합니다. 로컬에서 실행되는 프로그램은 통신 시점에 값을 메모리로 복원해야 하므로 역공학에 대한 절대적인 추출 불가를 보장하지는 않습니다.

## 구현된 기능

- 관문이나 기믹이 0개여도 오른쪽 디버프 목록과 `[기믹 없음]` 배정 문서를 항상 표시하고, 파티원별 디버프·그룹·커스텀 행동 지시를 토글·드래그로 즉시 저장·복사

- 전장의 서곡/행진곡/비바체/상태지원 버프 OCR 및 초 단위 카운트다운, 시간형 버프 아이콘을 놓치면 이름과 카운트다운을 함께 확인하는 안전한 OCR 보조 인식, 실제 활성·비활성 샘플 기반 비바체 판별

- 설정 창의 `.mabiutils-backup` 백업·복원, 손상·변조·과대 파일 사전 차단, 임시 파일과 롤백을 사용한 안전 교체, API 키·로그 제외
- 트레이에 숨은 기존 실행 감지 및 MabiUtils 다크 테마의 기존 창 열기·안전 교체·추가 실행·취소 선택창
- 메인 도움말 왼쪽 `패치 노트` 글자 링크와 최신순 가변 높이 날짜 카드·최신 배지·픽셀 휠 스크롤·스크롤바를 갖춘 사용자용 변경 요약 창
- 메인 `?`에서 여는 전체 사용자 도움말, 9개 메뉴 목차와 단계별 카드, 영역 지정의 준비·대상별 드래그 범위·저장 확인·스캔 시작·문제 해결 상세 안내, 독립 최소화와 픽셀 스크롤
- Direct2D 기반 현대식 다크 UI, 버튼·스위치·탭·선택박스·슬라이더 전환 애니메이션
- 메인/설정/프리셋/로그/오버레이 공통 포커스·호버·클릭 피드백과 작업 완료 토스트
- 애니메이션이 동작할 때만 16ms UI 타이머를 사용하고 완료·숨김·최소화 시 즉시 중지
- Windows의 애니메이션 끄기 설정과 원격 데스크톱 환경에서는 모션을 자동 축소

## 빌드

Visual Studio 2022 C++ Build Tools와 Windows 10/11 SDK가 필요합니다. PowerShell에서 다음을 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build.ps1
```

`build.ps1`은 기본적으로 프로젝트 상위의 `mabi\electron\main.cjs`에서 정확히 한 개의 `NEXON_OPEN_API_KEY` 선언을 읽습니다. 다른 승인된 평문 소스를 일회성으로 사용할 때는 `-EmbeddedSecretSource <절대 경로>`를 지정할 수 있으며, 소스는 빌드 직후 삭제하고 Git·로그·배포 폴더에 넣지 않아야 합니다. 값은 명령행이나 출력에 넣지 않고 매 빌드 새 AES-256-CBC 암호문과 HMAC-SHA256 인증 태그, 분할된 복원 자료를 생성해 EXE의 `RCDATA`에 포함합니다. 생성 자료가 없거나 형식이 잘못되면 보호 배포 빌드는 실패합니다.

빌드와 전체 테스트가 끝나면 실행 파일은 `release\MabiUtils.exe` 한 곳에만 배치되고 전체 `assets`가 함께 동기화됩니다. 동시에 실행 파일과 전체 assets만 담은 버전별 ZIP과 그 ZIP의 SHA-256을 기록한 `version.json`을 만듭니다. 프로젝트 최상단에는 중복 EXE를 만들지 않으며, 완성된 배포 파일은 [MabiUtilsRelease](https://github.com/Irha-12/MabiUtilsRelease)에도 함께 관리합니다. 다른 PC나 폴더로 전달할 때는 ZIP 전체를 압축 해제해야 아이콘과 음성이 깨지지 않습니다. 패키징 단계는 EXE와 모든 리소스의 파일 수·크기·SHA-256을 확인하며 하나라도 누락되거나 달라지면 빌드를 실패시킵니다. 마지막으로 Git 추적 파일, 생성 자료, 빌드 EXE와 전체 배포 폴더에서 실제 키의 UTF-8·UTF-16LE 평문을 검사하고 한 건이라도 발견하면 배포를 중단합니다. 저장소 소유권이 실행 사용자와 달라도 명시된 프로젝트의 추적 파일을 read-only로 검사하며 검사기 오류도 전체 빌드 실패로 전파합니다.
